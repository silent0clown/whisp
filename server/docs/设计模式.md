# 设计模式

## 1. 网络层（Network）

### 核心模式

| 模式              | 应用场景               | 实现示例                          |
|-------------------|-----------------------|-----------------------------------|
| Reactor           | 事件循环（EventLoop）  | `EventLoop` + `EpollPoller`       |
| Observer          | 回调机制（Callbacks）  | `Channel::setReadCallback()`      |
| Abstract Factory  | 多协议编解码器         | `Codec` 基类派生出 `BinaryCodec`/`JsonCodec` |
| State             | TCP连接状态管理        | `TcpConnection` 的 `state_` 状态转换 |

#### 代码示例

```cpp
// TCP连接状态管理示例
class TcpConnection {
    enum State { Connected, Disconnected, Connecting, Disconnecting };
    State state_;

public:
    void setState(State newState) {
        state_ = newState;
        handleStateChange();
    }

private:
    void handleStateChange() {
        switch (state_) {
            case Connected:
                // Handle connected state
                break;
            case Disconnected:
                // Handle disconnected state
                break;
            case Connecting:
                // Handle connecting state
                break;
            case Disconnecting:
                // Handle disconnecting state
                break;
        }
    }
};
```

```cpp
// Reactor模式核心结构
class EventLoop {
    std::unique_ptr<Poller> poller_;  // 多态持有Epoll/Kqueue
    void loop() {
        while (running_) {
            poller_->poll(activeChannels_);
            for (auto& channel : activeChannels_) {
                channel->handleEvent();  // 观察者模式回调
            }
        }
    }
};
```

## 2. 数据库层（DB）

### 核心模式

| 模式              | 应用场景               | 实现示例                          |
|-------------------|-----------------------|-----------------------------------|
| Connection Pool   | 数据库连接复用         | `MysqlxPool` 管理连接生命周期      |
| DAO               | 数据访问抽象           | `UserDao` 封装SQL操作             |
| Active Record     | 简单ORM映射            | `class User : public ActiveRecord` |
| Proxy             | 连接失败重试机制       | `RetryProxyConnection` 包装原始连接 |

#### 代码示例

```cpp
// 连接池实现（Singleton + Object Pool）
class MysqlxPool {
    static MysqlxPool& instance();  // 单例
    std::queue<Connection*> pool_;  // 连接池
    Connection* getConnection() {   // 获取连接（惰性创建）
        if (pool_.empty()) createNewConnection();
        return pool_.front();
    }
};
```

## 3. 核心业务层（Core）

### 核心模式

| 模式                  | 应用场景               | 实现示例                          |
|-----------------------|-----------------------|-----------------------------------|
| Strategy              | 不同消息处理策略       | `MessageHandler` 接口的不同实现    |
| Chain of Responsibility | 消息处理流水线        | `MessageBroker` 中的处理器链       |
| Session State         | 用户会话状态管理       | `Session` 的 `State` 子类         |
| Command               | 可撤销操作（如消息撤回）| `RevokeMessageCommand`            |

#### 代码示例

```cpp
// 责任链模式处理消息
class MessageHandler {
    MessageHandler* next_;
public:
    virtual void handle(Message& msg) {
        if (canHandle(msg)) process(msg);
        else if (next_) next_->handle(msg);  // 传递请求
    }
};
```

## 4. 工具层（Util）

### 核心模式

| 模式              | 应用场景               | 实现示例                          |
|-------------------|-----------------------|-----------------------------------|
| Singleton         | 日志管理器/配置读取     | `LogManager::instance()`          |
| Builder           | 复杂对象构造（如加密参数）| `CryptoParamsBuilder`             |
| Facade            | 简化复杂工具库调用      | `ZlibWrapper` 封装zlib接口         |

#### 代码示例

```cpp

class LogManager {
    static LogManager& instance() {

        return inst;
    }
    void log(const std::string& msg) { /*...*/ }
};
```

## 设计模式应用原则

- **网络层**：优先性能（`Reactor` + `Observer`）
- **数据库层**：保证线程安全（`Connection Pool` + `DAO`）
- **业务层**：强调扩展性（`Strategy` + `Chain`）
- **工具层**：注重简洁（`Singleton` + `Facade`）
